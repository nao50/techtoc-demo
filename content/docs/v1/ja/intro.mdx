このサイトは **GitHub のリポジトリ（`nao50/techtoc-demo`）から取り込まれています**。
`content/` の中を編集して `main` に push すると、techtoc が取り込んでサイトを
作り直します。

:::note
この頁は「取り込みの見本」です。**サイドナビの階層**（区分 → 小区分 → 記事）と、
複数の collection（ドキュメント・ハンズオン）が、リポジトリのディレクトリから
どう組み上がるかを見せています。
:::

## 何が置いてあるか

| 区分 | 中身 |
| --- | --- |
| ガイド → ネットワーク | 接続の考え方と設定 |
| ガイド → 認証方式 | 方式の選び方 |
| リファレンス | 属性・エラーの一覧 |
| 運用 | 監視とバックアップ（既定は畳んでいます） |

## サイドナビの階層はどう決まるか

ディレクトリがそのまま階層になります。区分の**名前と並び順**は
`content/docs/v1/_structure.json` に書きます。

```
content/docs/v1/ja/
  intro.mdx                    ← この頁
  setup.mdx
  guide/
    networking/                ← 「ネットワーク」区分
      overview.mdx
      vlan.mdx
    auth/                      ← 「認証方式」区分
      methods.mdx
      certificates.mdx
  reference/
    attributes.mdx
  operations/
    monitoring.mdx
    backup.mdx
```
