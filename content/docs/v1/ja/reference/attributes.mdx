認証が通ったとき、機器の扱いを属性で指示します。

## VLAN

| 属性 | 値 |
| --- | --- |
| Tunnel-Type | VLAN |
| Tunnel-Medium-Type | IEEE-802 |
| Tunnel-Private-Group-ID | VLAN 番号 |

## 時間

| 属性 | 意味 |
| --- | --- |
| Session-Timeout | 秒。過ぎたら切る（再認証の間隔にもなる） |
| Idle-Timeout | 秒。無通信がこれだけ続いたら切る |

使い方は [VLAN の割り当て](/demo/ja/docs/guide/networking/vlan) を見てください。
