This site is **synced from a GitHub repository** (`nao50/techtoc-demo`).
Edit files under `content/` and push to `main`; techtoc pulls them in and
rebuilds the site.

:::note
This page is a sync example. It shows how the **sidebar hierarchy**
(section → subsection → article) and multiple collections are assembled
from the repository's directory layout.
:::
